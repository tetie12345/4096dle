# Wordle Clone

A self-contained browser-based Wordle clone. Open `index.html` in any browser.

## Features
- 6x5 grid
- On-screen keyboard + physical keyboard support
- Color feedback (green = correct, yellow = present, gray = absent)
- Word validation against a built-in dictionary
- Win/lose detection and "New Game" button

## Run
Just open `index.html` in a browser. No build step required.
